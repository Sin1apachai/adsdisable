# X Ads icon

Created using the built-in OpenAI image generation tool, then downscaled to 16, 32, 48, 128 and 256 pixel PNG files. The final asset uses an opaque white background around a red rounded tile, a white X and a small browser badge. Icon source is generated artwork; these assets are not from EasyList.

Generation prompt:

> Use case: logo-brand. ONE final app icon for a minimalist Chrome ad-blocking extension named X Ads. Red and white only. A bold red rounded-square tile with a large very crisp white X formed by two thick diagonal rounded strokes; in the upper right of the X a tiny simple white browser-window cutout with one red horizontal dash to subtly suggest removing an ad, but overall X must remain extremely clear at 16 px. Premium minimal geometric flat icon, no text, no letters other than abstract X, no mockup, no shadows, no gradient, no 3D, no watermark. Centered tile occupies 90% of square with transparent outside rounded corners. Color scarlet #E53935 and pure white #FFFFFF. Single icon, not a grid.

Final refinement prompt:

> Refine this app icon into a flawless flat graphic. Keep the white X and small white browser badge, but remove ALL texture, shading, gradients, transparency, holes, noise, glow and ragged edges. The rounded-square tile must be ONE perfectly uniform flat solid scarlet red #E53935. Background outside the rounded square must be pure opaque white #FFFFFF. Perfectly crisp smooth geometric edges. No additional text, no mockup. White X centered and large, browser badge top right, balanced composition. Square canvas.
