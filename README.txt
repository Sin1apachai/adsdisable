ClearAds — ส่วนขยายบล็อกโฆษณาทั่วไป รุ่น 1.5.1

วิธีติดตั้ง
1. เปิด Google Chrome แล้วพิมพ์ chrome://extensions ในแถบที่อยู่
2. เปิด Developer mode / โหมดนักพัฒนาซอฟต์แวร์ ที่มุมขวาบน
3. คลิก Load unpacked / โหลดส่วนขยายที่คลายการแพ็ก
4. เลือกโฟลเดอร์ ClearAds บน Desktop (โฟลเดอร์ที่มี manifest.json)
5. กดไอคอนจิ๊กซอว์ใน Chrome แล้วปักหมุด ClearAds
6. รีเฟรชหน้าเว็บที่เปิดอยู่ก่อนติดตั้ง

ใช้งาน
- เปิดป๊อปอัปเพื่อเปิด–ปิดการบล็อกทั้งหมด หรือยกเว้นเว็บไซต์ปัจจุบัน
- การยกเว้นครอบคลุมเว็บไซต์นั้นและโดเมนย่อย
- ถ้าถูกยกเว้นจากโดเมนแม่ ให้กลับไปเปิดการบล็อกที่โดเมนแม่
- หลังเปลี่ยนค่า ให้กดรีเฟรชหน้านี้
- หากเว็บแสดงผลผิด ให้ยกเว้นเว็บนั้นแล้วรีเฟรช

ขอบเขต
ใช้รายการโดเมนโฆษณาที่รวมมากับส่วนขยายและซ่อนช่องโฆษณาที่รู้จัก
ไม่ได้บล็อกโฆษณาครบทุกเว็บ และไม่รับประกันโฆษณา YouTube, Facebook หรือโฆษณาที่ส่งจากโดเมนเดียวกับเนื้อหา
รายการไม่ได้อัปเดตอัตโนมัติ ไม่ใช่ผลิตภัณฑ์ของ Google และยังไม่ได้เผยแพร่บน Chrome Web Store

ความเป็นส่วนตัว
ไม่มีระบบวิเคราะห์ ไม่มีการส่งข้อมูลออก และไม่เก็บประวัติการท่องเว็บ
บันทึกเฉพาะสถานะเปิด–ปิดและเว็บไซต์ที่ยกเว้นในเครื่อง
สิทธิ์เข้าถึงหน้าเว็บใช้เพื่อซ่อนช่องโฆษณา ส่วน activeTab ใช้ดูเว็บไซต์ที่คุณเปิดป๊อปอัป
ไม่ลบโฟลเดอร์นี้ขณะที่ยังใช้งานส่วนขยายอยู่

เอกสาร API: https://developer.chrome.com/docs/extensions/reference/api/declarativeNetRequest/
