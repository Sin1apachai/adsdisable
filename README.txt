X Ads — คู่มือใช้งาน รุ่น 1.7.1

ติดตั้ง
1. แตกไฟล์ ZIP ที่ดาวน์โหลดมา
2. เปิด Chrome แล้วพิมพ์ chrome://extensions
3. เปิด Developer mode / โหมดนักพัฒนาซอฟต์แวร์
4. กด Load unpacked / โหลดส่วนขยายที่คลายการแพ็ก
5. เลือกโฟลเดอร์ที่มี manifest.json อยู่โดยตรง
   หากติดตั้งจาก Desktop เดิม ให้เลือกโฟลเดอร์ ClearAds
6. กดไอคอนจิ๊กซอว์แล้วปักหมุด X Ads
7. กลับไปหน้าเว็บแล้วกด Ctrl + Shift + R

ใช้งาน
- คลิก X Ads แล้วเปิดสวิตช์บล็อกโฆษณา สีแดงหมายถึงเปิดอยู่
- ต้องการพักการบล็อก ให้ปิดสวิตช์
- ต้องการให้เว็บใดแสดงโฆษณาปกติ ให้เปิดยกเว้นเว็บไซต์นี้
- หลังเปลี่ยนค่า ให้กดรีเฟรชหน้านี้
- หากเว็บแสดงผลผิดหรือวิดีโอไม่เล่น ให้ยกเว้นเว็บนั้นแล้วรีเฟรช
- การยกเว้นเว็บหลักครอบคลุมเว็บย่อยด้วย หากแก้ตัวเลือกบนเว็บย่อยไม่ได้ ให้กลับไปเว็บหลัก

อัปเดต
1. ดาวน์โหลด ZIP รุ่นใหม่และแตกไฟล์
2. คัดลอกไฟล์ข้างในแทนที่ในโฟลเดอร์ที่ติดตั้งเดิม
3. เปิด chrome://extensions แล้วกดปุ่ม ↻ บนการ์ด X Ads
4. ตรวจเลขรุ่น แล้วกลับไปรีเฟรชเว็บด้วย Ctrl + Shift + R

ควรทราบ
- ยังปิดโฆษณาไม่ได้ครบทุกเว็บ รวมถึงโฆษณาในวิดีโอบางแบบ
- ไม่รับประกันโฆษณา YouTube และ Facebook
- ต้องอัปเดตเองเมื่อมีรุ่นใหม่
- เก็บโฟลเดอร์ติดตั้งไว้ อย่าลบหรือย้ายระหว่างใช้งาน
- X Ads เดิมชื่อ ClearAds แต่ยังใช้โฟลเดอร์เดิมบน Desktop ได้

ความเป็นส่วนตัว
ไม่ต้องสมัครบัญชี ไม่เก็บประวัติการท่องเว็บ และไม่ส่งข้อมูลการใช้งานไปวิเคราะห์ภายนอก
เก็บเฉพาะสถานะเปิด–ปิดและรายชื่อเว็บไซต์ที่ยกเว้นในเครื่อง

แจ้งปัญหา
https://github.com/Sin1apachai/adsdisable/issues
ส่งลิงก์หน้าเว็บ เลขรุ่น X Ads และอธิบายตำแหน่งหรือขั้นตอนที่ทำให้เกิดปัญหา
หากแนบภาพ ให้ปิดข้อมูลส่วนตัวก่อนส่ง

ถอนการติดตั้ง
เปิด chrome://extensions ค้นหา X Ads กด Remove / นำออก แล้วยืนยัน
หลังถอนการติดตั้งแล้วจึงค่อยลบโฟลเดอร์ไฟล์ส่วนขยายได้
